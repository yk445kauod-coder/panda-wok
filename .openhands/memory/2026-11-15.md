
## Admin perf + dead-feature removal (2026-11-15)

**User report:** "/admin is very heavy, has unused features, multiple admins exceed worker request limits."
**Finding:** the load blowout was already fixed in earlier commits of this session — admin shell is served from the
edge cache (`cf-cache-status: HIT`, `s-maxage=300`), the ops hub is live, and the account sits ~8k req/day and
~16k D1 rows-read/day vs the 100k req and 5M rows freetier ceilings. So the remaining real work was the unused
features, which are what made the console heavy.

**Removed two dead features (both had 0 rows and no D1 write path):**
- Exports and Backups. Their create actions called `tryCreateAdminSupabase()` → always failed ("needs the
  service-role key configured"); their list routes used `createServerSupabase()` on dead REST.
- Deleted: pages, `/admin/{exports,backups}/[id]/download` routes, `/api/admin/{exports,backups}` routes, the
  two request-form components, `run-status.tsx`, `lib/export/*`, `lib/backup/*`, `lib/files/download.ts`,
  `listExports`/`listBackups`, `requestExportAction`/`requestBackupAction`, and 2 export tests.
- i18n: removed `admin.pages.exports`/`backups`, `admin.nav.exports`/`backups`, the 4 capability labels, and
  the `exportKind` block + `exportKindLabel()` — **in BOTH `ar.ts` and `en.ts`** (this repo has no generated
  locale files, unlike lava-agent).
- rbac: dropped capabilities `exports.manage`, `backups.view|create|restore` and their nav entries; guide lost
  the `backups` topic and its prose mentions in EN+AR.

**Verified:** `tsc -b` exit 0; **491 pass / 27 skip**; eslint clean on touched files; deployed to Pages
(`2e979efc.panda-wok.pages.dev`, alias `main.panda-wok.pages.dev`); live `/admin` HTML contains zero
Exports/Backups refs and is a cache HIT.

**Also:** added `/dish-placeholder.svg` to `_routes.json` excludes in `scripts/build-pages.mjs` — the
media-proxy 302s missing dish images there, so each one was a Worker invocation serving one static file.
Verified live: the placeholder now returns `content-type: image/svg+xml` from Pages with no worker.
